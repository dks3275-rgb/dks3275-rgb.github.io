# 📱 APK 파일 업로드 안내

이 폴더에 APK 파일을 업로드하면 사용자가 직접 다운로드할 수 있습니다.

## 📤 업로드 방법

1. APK 파일을 **`AU일학습병행.apk`** 라는 이름으로 변경
2. 이 폴더에 복사
3. GitHub에 push

## 🔗 다운로드 URL

업로드 후 자동으로 다음 URL에서 접근 가능:
```
https://dks3275-rgb.github.io/apk/AU일학습병행.apk
```

## ⚠️ 주의사항

- **파일 크기**: GitHub 제한 100MB 이하 (일반 APK는 5~15MB)
- **사용자 안내**: 다운로드 시 "출처 불명 앱 허용" 필요
- **자동 업데이트**: APK는 자동 업데이트 안 됨 (수동 재설치 필요)
- **버전 관리**: 새 버전 출시 시 같은 파일명으로 덮어쓰기

## 📊 추천 흐름

```
사용자 방문
   ↓
install.html 자동 감지
   ↓
Android → APK 직접 다운로드 또는 PWA 설치
iOS → PWA 설치만 가능
```
