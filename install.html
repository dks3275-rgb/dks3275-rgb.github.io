APK 직접 설치
정식 앱처럼 폰에 설치되는 가장 좋은 방법
⬇️ APK 다운로드 (즉시 설치)
  • 일반 앱처럼 작동
  • 홈 화면 아이콘 자동 등록
  • 알림 안정적 수신
  • "출처 불명 앱 허용" 필요
🌐
웹 앱 (PWA)으로 설치
브라우저에서 바로 사용, 설정 단순
🚀 웹앱으로 시작하기
  • 즉시 사용 가능
  • 설정 단순
  • 홈 화면 추가는 직접 해야 함
📥 APK 설치 단계
1
APK 파일 다운로드
2
다운로드 알림 또는 파일 관리자에서 APK 클릭
3
"출처 불명 앱 허용" 메시지 → 설정으로 이동 → 허용
4
"설치" 버튼 클릭 → 완료!
5
앱 실행 → 알림 권한 허용 → 가입 진행
🌐
홈 화면에 추가 (Safari)
아이폰은 Safari에서만 설치 가능합니다
🚀 시작하기
  • 홈 화면 아이콘으로 일반 앱처럼 사용
  • 알림 수신 가능 (iOS 16.4+)
📲 iOS 설치 단계 (Safari)
1
이 페이지를 Safari에서 열기
2
화면 하단 공유 버튼 (□↑) 누르기
3
"홈 화면에 추가" 선택
4
"추가" 클릭 → 완료!
